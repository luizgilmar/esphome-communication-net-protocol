# Desenvolvimento e controle

Este repositório no OneDrive é a fonte de controle do projeto. Manter aqui código, configurações, documentação, testes e histórico Git. Somente diretórios de build e caches de compilação ficam fora do OneDrive, preferencialmente em AppData/Local.

Não criar cópias paralelas de desenvolvimento em Documents/Codex/work ou outputs. Essas áreas contêm entregas e material histórico. Para compilar, apontar ESPHOME_BUILD_PATH e ESPHOME_DATA_DIR para fora do OneDrive; não copiar código ou secrets para outra árvore de desenvolvimento.

As alterações locais desta colaboração são partes do mesmo trabalho. Conferir o histórico e reconciliar essas alterações, sem presumir origem externa. Preservar e versionar o trabalho consolidado. Consumidores dos componentes devem usar referências Git fixas; não distribuir fontes locais para o HA.
